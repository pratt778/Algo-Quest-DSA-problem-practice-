[![Android](https://img.shields.io/badge/Platform-Android-green.svg)](https://www.android.com)

[![License](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

**AlgoQuest** is a powerful native Android app for practicing Data Structures and Algorithms (DSA). Solve real problems by writing JavaScript code, get instant feedback, and enjoy smart recommendations powered by advanced algorithms—all on your mobile device!












## Key Features

- **JavaScript Code Execution**  
  Submit JS code for DSA problems—securely executed server-side using a Kotlin-based JS runtime (GraalVM).








- **Secure Login**  
  Seamless Google Sign-In with Firebase Authentication.




- **Intelligent Search**  
  Trie-based autocomplete for lightning-fast suggestions and fuzzy search for flexible queries.








- **Learning Path Guidance**  
  Topological sort to recommend prerequisite problems in optimal order.

- **Personalized Recommendations**  
  After solving a problem, discover similar ones via **Dijkstra's algorithm** on a problem similarity graph.




## Tech Stack

- **Frontend**: Kotlin with Jetpack Compose
- **Backend**: Firebase (Authentication & Firestore)
- **Code Execution**: GraalVM JS engine in Kotlin server
- **Algorithms**: Trie, Fuzzy Search, Topological Sort, Dijkstra

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/pratt778/Algo-Quest-DSA-problem-practice-.git
   ```
2. Open in Android Studio.
3. Add your Firebase `google-services.json`.
4. Build and run!
